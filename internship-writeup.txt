2. PROJECT UNDERTAKEN / COMPLETED
-----------------------------------
Project Title:
SENTINEL - A SIEM Dashboard for Security Operations Center (SOC)

Project Overview:
SENTINEL is a frontend-complete, presentation-ready SIEM dashboard
prototype designed to simulate the core workflows used by security analysts
in a modern SOC environment. The project demonstrates real-time threat
monitoring, incident response management, log investigation, and threat
intelligence correlation — key functions of any enterprise SIEM platform.

The application consists of four functional modules:

  a) SOC Dashboard — Real-time monitoring with live event simulation,
     global attack map, threat timeline charts, severity distribution,
     and system health status panels.

  b) Incident Response — A complete incident lifecycle management system
     supporting analyst assignment, status workflow (New → Triaged →
     In Progress → Containment → Eradication → Recovery → Closed),
     and timestamped activity timelines.

  c) Log Search — An investigation workspace for searching, filtering,
     and exporting system logs using keyword or regex queries, with
     CSV and JSON export capabilities.

  d) Threat Intelligence — An IOC (Indicator of Compromise) management
     module for reviewing malicious indicators, threat campaigns, actor
     attribution, MITRE technique mappings, and enrichment status.

Project Status:
The frontend is 90-95% complete and fully presentation-ready. The backend
is simulated using a typed mock API adapter, with all data boundaries
prepared for future real backend integration.


3. ROLES AND RESPONSIBILITIES
-------------------------------
As the developer on this project, the following responsibilities were undertaken:

  - Designed and implemented the complete multi-page React application
    architecture with React Router (Dashboard, Incidents, Log Search,
    Threat Intel, 404 fallback)

  - Built the SOC Dashboard including: metric cards, canvas-based global
    attack map with animated attack paths, recharts-based threat timeline
    and severity donut chart, filterable and expandable security events
    table, system health panel, and top attack origins widget

  - Implemented the real-time event simulation engine using a custom React
    hook (useEventSimulation) that generates deterministic security events
    for live demo purposes

  - Integrated MITRE ATT&CK framework mappings to each security event,
    providing tactic/technique identification and recommended analyst
    response actions

  - Developed the Incident Response page including full workflow state
    management, analyst assignment, status progression with automatic
    timeline logging, and localStorage-backed persistence

  - Built the Log Search module with keyword/regex search, query
    highlighting, severity and source filtering, result limiting for
    performance, and CSV/JSON export functionality

  - Created the Threat Intelligence page with IOC list, IOC detail panel,
    campaign tracking cards, enrichment simulation, and multi-field filtering

  - Implemented the notification system with a dismissible alert dropdown,
    per-alert acknowledgement, acknowledge-all functionality, and badge count

  - Set up the project's quality infrastructure: ESLint, TypeScript strict
    mode, Vitest unit tests, Playwright browser verification tests, and
    Vite production build with chunk optimization

  - Wrote meaningful unit tests covering dashboard rendering, event
    expansion, header search routing, incident drill creation, status
    advancement, threat intel filtering, and alert acknowledgement

  - Maintained dark/light theme with localStorage persistence and ensured
    full responsive layout compatibility across desktop and mobile viewports


4. TECHNOLOGIES / TOOLS USED
------------------------------
Frontend Framework:
  - React 18 with functional components and hooks
  - TypeScript for type safety across all components and data models

Build Tooling:
  - Vite (fast build tool and dev server with HMR)
  - PostCSS and Autoprefixer

Styling:
  - Tailwind CSS with HSL design tokens and custom theming
  - shadcn/ui component library (built on Radix UI primitives)
  - Framer Motion for UI animations
  - Lucide React for icons

Data Visualization:
  - Recharts for threat timeline and severity distribution charts
  - HTML5 Canvas API for the global attack map

Routing and State:
  - React Router DOM v6 for client-side routing
  - React Hook Form with Zod for form validation
  - TanStack React Query for data management patterns
  - localStorage for session persistence (incidents, alerts, theme)

Testing:
  - Vitest as the test runner
  - Testing Library (React) for component testing
  - Playwright for end-to-end browser verification

Code Quality:
  - ESLint with TypeScript-ESLint rules
  - TypeScript strict mode compilation

Backend (Mock/Simulated):
  - Node.js mock API server (mock-api.mjs) serving mock data on port 3001
  - Typed mock data layer in src/data/ (siem-data.ts, mitre-data.ts,
    threat-intel-data.ts)
  - Mock API adapter in src/lib/sentinel-api.ts as backend integration
    boundary
