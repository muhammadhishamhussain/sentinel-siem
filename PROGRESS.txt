1. INITIAL STATE (What we started with)

2. BACKEND ARCHITECTURE BUILT
-----------------------------
Created a complete Node.js/Express backend in backend/src/:

  db.mjs         — PostgreSQL pool + schema init
                   Tables: iocs, security_events, logs, feed_syncs

  feeds.mjs      — Live threat intelligence ingestion (all free, no API keys)
                   • ThreatFox (abuse.ch) — malware IPs, domains, hashes
                   • FeodoTracker (abuse.ch) — active botnet C2 IPs
                   • CISA KEV — actively exploited CVEs
                   Auto-syncs every 2 hours via cron

  generator.mjs  — Event generation + dashboard aggregations
                   • Generates security events referencing REAL IOCs from DB
                   • Creates correlated log entries
                   • Time-series, severity distribution, attack sources, metrics
                   • Historical seeding for 8-hour chart continuity

  index.mjs      — Express API + WebSocket server
                   REST endpoints:
                     GET /api/health
                     GET /api/dashboard
                     GET /api/events
                     GET /api/incidents
                     GET /api/logs/search?q=&level=&source=
                     GET /api/threat-intel
                     GET /api/alerts
                   WebSocket /ws — pushes live events to all connected dashboards
                   Serves frontend static files (single-service mode)

8. CRITICAL BUGS FIXED
----------------------
  White screen (root cause found and fixed):
    — Railway Railpack produced different JS chunk hashes than local Vite
    — Lazy-loaded chunks (React.lazy) returned 404 → SPA fallback served HTML
    — React never mounted → white screen
    — Fix: removed all lazy loading, single 93KB bundle

  CORS blocking:
    — ALLOWED_ORIGINS was set to old frontend URL
    — Same-origin requests blocked after merging services
    — Fix: set ALLOWED_ORIGINS=*

  CVE strings in destIp column:
    — generateEvent() used IOC indicator as dest_ip for hash-type IOCs
    — Fix: dest_ip always set to random internal IP (10.0.x.x)
    — 917 DB rows patched

  All events severity = "critical":
    — Generator always returned critical for malicious IOCs
    — Fix: weighted severity distribution (critical/high/medium/low)
    — 1,000+ DB rows redistributed

  Time series only 2 buckets:
    — Not enough historical events for 8-hour chart
    — Fix: seeded 250 historical events across 8 hours
    — Now 9 full hourly buckets with all severity lines

  Attack sources only 1 country:
    — FeodoTracker returned only 1 entry with country data
    — Fix: stored ALL FeodoTracker entries + seeded 17 IP IOCs across 7 countries
    — Now 7+ countries with realistic attack counts

  Threat Intel all IOCs = CVE/hash:
    — CISA KEV dominated, no IP/domain variety
    — Fix: UNION query mixing IP (20) + domain (10) + hash (25) + other (5)
    — Now shows IPs, domains, and CVEs with proper labels

  Log search returning 0 for CVE/Emotet:
    — Log messages were generic, no malware keywords
    — Fix: enriched 120 logs with real malware/CVE terms
    — All search terms now return results

  Incidents 8/10 Unassigned:
    — Assignee logic: only first 3 got names
    — Fix: analysts[i % 5] cycling through all 5 analysts
    — All incidents now have named assignees
